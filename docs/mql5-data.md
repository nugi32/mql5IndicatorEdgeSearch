# MQL5 Data and Exporters

The Python pipeline consumes bar and feature data exported from MetaTrader 5. The exporter is the source of the indicator values; Python does not attempt to reproduce the MT5 indicator formulas.

## Exporting price and indicator data

Use [mql5/dataExporter.mq5](../mql5/dataExporter.mq5) in the MT5 Strategy Tester to export historical bars and indicator values. The exported rows include timestamps, OHLCV data, standard indicator features, and supported custom-indicator fields. The exporter runs incrementally by bar and writes a CSV suitable for `scripts/run_pipeline.py` and `scripts/run_walkforward_pipeline.py`.

For the data export, the exporter documentation recommends the MT5 **Open prices only** model because values are collected per bar. Export enough history for the selected research profile, and verify symbol, timeframe, date range, bar count, timestamp ordering, and indicator warm-up values before starting an expensive run.

## Additional MQL5 programs

| Source | Role |
|---|---|
| `mql5/dataExporter.mq5` | Main historical OHLCV/indicator CSV exporter; also supports exported news features |
| `mql5/economicCalendar.mq5` | Economic-calendar export from a live chart; the MT5 calendar API is unavailable in Strategy Tester |
| `mql5/spreadExporter.mq5` | Historical per-bar spread export for cost calibration and backtesting |
| `mql5/VolRegime_ATR.mq5` | Custom volatility-regime indicator consumed by the main exporter |
| `mql5/priceStructure.mq5` | Custom price-structure indicator consumed by the main exporter |

Custom indicators must be compiled and available to MT5 as required by the exporter. The source comments declare tester-indicator dependencies. A missing or invalid indicator may result in missing values; inspect exporter logs and the resulting CSV.

## Input data and ingestion

The loader expects a `time` column and numeric columns for market data/features. It parses supported exporter timestamp formats, cleans numeric cells, converts numeric data to `float32`, and stores a Parquet cache. Malformed timestamps may be dropped with a warning; review ingestion logs and row counts rather than assuming every input row was accepted.

The pipeline treats time as broker/server time. Calendar attachment does not automatically convert time zones, so bar and calendar timestamps must use a compatible clock.

Data files are not guaranteed to be included in a checkout. Supply your own valid export; the `data/raw_csv/` directory is a conventional location, not proof that a sample CSV is present.

## Feature families

- Standard exported indicators include moving averages, oscillators, volatility indicators, directional indicators, and volume features.
- `volregime_*` and `ps_*` columns are produced by the custom indicators when available.
- `news_*` columns are generated by the MQL5 exporter when supported news features are enabled and calendar input is available.
- `cal_*` columns are derived in Python when `--calendar-csv` is supplied.

The exact set of exported columns depends on the exporter version, its inputs, and the available MT5 indicators. Only columns present and usable in a particular CSV can participate in candidate generation.

## Calendar data

The MT5 calendar API does not work in the Strategy Tester. The exporter can use a calendar file collected from a live chart to add `news_*` features. Separately, passing `--calendar-csv` lets Python add `cal_*` features using `edge_research/ingestion/economic_calendar.py`.

Calendar-derived features use the event schedule and previously released event data with look-ahead safeguards. Coverage is important: bars outside the calendar file's time coverage are marked missing, not treated as quiet/no-news bars. Check the exporter schema and configuration for selected currencies and importance thresholds.

Conditions involving calendar/news columns are marked in reports and gate results because they cannot be reproduced identically through the Strategy Tester calendar API. They require separate verification before any deployment.

## Custom-indicator caveat

The exporter and the generated EA must use compatible custom-indicator binaries, inputs, and buffer meanings. In particular, inspect the `PriceStructure` implementation and export timing before treating `ps_*` values as equivalent to standard indicators sampled at bar close. The exporter and indicator may expose values at different points in bar formation.

## Spread calibration

Use `mql5/spreadExporter.mq5` to collect per-bar spread data. Summarize it or update a tester profile with:

```bash
python scripts/calibrate_mt5_spread.py path/to/symbol_timeframe_spread.csv
python scripts/calibrate_mt5_spread.py path/to/symbol_timeframe_spread.csv \
  --update-config config/MT5_TESTER/XAUUSD/H1.yaml
```

The script reports descriptive statistics and a mean-based fixed-spread suggestion. For a test with time-varying costs, pass the spread file using `--mt5-spread-csv` on a pipeline run or `--spread-csv` on `run_mt5_backtest.py`. Verify the file's point units and symbol match the tester configuration.
